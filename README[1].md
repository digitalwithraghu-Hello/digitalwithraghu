# Digital with Raghu — GitHub Pages Website

A responsive static website for Digital with Raghu.

## Files
- `index.html` — website structure/content
- `style.css` — responsive design
- `script.js` — mobile menu, reveal animations and contact form
- `assets/` — place your images here

## Before publishing
1. Open `script.js`.
2. Replace `hello@digitalwithraghu.com` with your real email address.
3. In `index.html`, replace the "YOUR PHOTO" block with your professional photo if desired.
4. Update any service descriptions, testimonials and case studies with verified information only.

## Publish with GitHub Pages
1. Create a GitHub repository named `digitalwithraghu.github.io` (or another repository name).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/`.

## Custom domain
When you are ready to use `digitalwithraghu.com`, add the domain under **Settings → Pages → Custom domain**, then update the DNS records at your domain registrar as GitHub instructs.

No framework or build step is required.
